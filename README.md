# ADDo

Gamified task manager for ADHD-friendly flexible workers. **A**ttention **D**eficit **D**isordered **"Do"**ing.

Built on Expo (React Native + React Native Web) with a Supabase backend. One codebase, iOS + Web.

## Status

Early planning → scaffolding. See [BUILD_ROADMAP.md](BUILD_ROADMAP.md) for the full product spec and feature lock list, and [CLAUDE.md](CLAUDE.md) for development rules.

## Quick start

_Once scaffolded (coming in Session 1):_

```bash
npm install
cp .env.example .env.local   # fill in Supabase URL + anon key
npm run dev                  # Expo dev server
npm run web                  # run in a browser
```
